# Ria 入口图标候选 · 海浪 / 海螺

按「图标用海浪或海螺」重做的 6 个候选，与上层目录的几何候选（涟漪 / 交叠 / 标签页 / 服务铃 / 钥匙 / R）并列，供挑选。本目录只放候选，`lib/client.js` 的 `RiaIcon` 未改动。

## 共同规格

- 24×24 viewBox，`fill="none"`，纯 stroke，无渐变、阴影、底色；
- `stroke="currentColor"`，`stroke-linecap/linejoin="round"`，线宽 1.7；
- 主体落在 24 网格中央约 16px 光学框内；侧栏以 18px 显示，优先保证 16–18px 轮廓。

## 逐版说明

### v1 双浪 · 潮汐
- 两道相位错开的波线，最接近「水 / 潮」的通用符号；16px 下仍是两条清楚的波纹。
- 代价是语义偏「水」而不偏「管家」，适合先立「汐」的品牌，再靠文案补职责。

### v2 卷浪 · 起势
- 一条涌起的浪脊 + 内卷的浪舌 + 底部水线，是六版里动势最强的一版；48px 下最像「浪」。
- 16px 时内卷缩成一个小环，和水线一起看略像眼睛；若选它，建议 18px 以上使用，或把内卷再张开一点。

### v3 浪环 · 往复
- 圆环收住一道波，取「潮起潮落、周而复始」；圆环也让它在侧栏里和 DSH 现有圆形图标同族。
- 16px 下圆环 + 单波都还在，是海浪组里小尺寸最稳的一版。

### v4 螺旋海螺
- 单条对数螺旋，开口留在左下；48px 下壳层清楚，是最「海螺」的一版。
- 16px 时内圈并成实心点，只剩外圈 + 点，像「@ / 蜗牛」；建议 20px 以上使用。

### v5 海螺 · 归潮
- 小螺旋浮在一道波上，「潮水把壳送回来」，和 slogan「every wave comes home」直接对应。
- 48px 下叙事最完整；16px 时螺旋退化成点，主要靠下面的波线识别。

### v6 鹦鹉螺 · 层叠
- 外圈留缺口 + 内螺旋，取鹦鹉螺的层叠舱室，比 v4 多一层「收拢 / 归档」的暗示。
- 24px 以上层次最好；16px 时缺口和外圈都还在，但内螺旋同样会并成点。

## 取舍建议

- 18px 侧栏、要小尺寸可读：**v1 / v3** 最稳，v2 次之。
- 要「海」的品牌感、且入口有机会用 24px 以上：**v5** 叙事最好，**v4** 最纯粹。
- 海螺组在 16px 都会退化成螺旋点；若最终选海螺，建议把入口图标尺寸提到 20px，或只在小尺寸换用 v1/v3。

## 实现提示

选定后只需把 `RiaIcon` 的子元素换成对应 `d`/`circle`，尺寸与 `currentColor` 接口不变；v4–v6 是折线逼近的螺旋（约 96 段），渲染成本可忽略，若在意文件体积可再拟合为 3–4 段贝塞尔。
