# 水元素位图候选 v3

一句话：这一轮先用位图找“潮汐的动势”，不急着画矢量。12 张里 **A1 最接近“潮水涌起又回卷”**，**C4 最像一枚入口图标**，**B1 最像潮涡**；B2、C3 缩小后不合格，不建议进入矢量阶段。

## 生成方式

- 模型：`gemini-3.1-flash-image`
- 接口：Friday AIGC 网关的 `imageGenerate` / `imageGenerateQuery`
- 参数：`aspectRatio: "1:1"`、`imageSize: "1K"`、每条固定 seed（A1–A4 为 101–104，B1–B4 为 201–204，C1–C4 为 301–304）
- 输出：模型原图下载后用 PIL `ImageOps.fit` 归一到 **1024×1024 PNG**，白底；除此之外没有修图、没有描边、没有改色
- 并发：3 路；12 张全部成功，单张约 10–22 秒
- 原始文件：`raw/A1.png` … `raw/C4.png`
- 对比图：`contact.png`，4 列×3 行，浅灰底白卡，每张 **220px**，标 ID 与“方向·名称”
- 生成脚本与提示词：`.gen/generate.py`、`.gen/prompts.json`
- 凭证不写进仓库：脚本从环境变量 `AIGC_APPID` 读取 appid，运行前自行设置

> 这批图是“概念位图”，边缘带笔刷纹理和灰阶抗锯齿，不是最终矢量。选定方向后仍要按 24×24、`fill="none"`、`stroke="currentColor"` 重画，不能直接描图。

## 先看结论

- **A1（卷浪梢·单峰回卷）**：潮汐感最强，左下长尾 + 右上内卷 + 两颗小水珠，18px 仍能看出“浪在翻”。细节偏多，矢量阶段要删掉大部分飞白。
- **C4（液态 R·倒影）**：最像“入口图标”的一张，实心 R 剪影 + 顶部浪冠 + 后退的腿，18px 仍有完整轮廓；极小尺寸有被读成 A/R 之间的可能。
- **B1（回旋环流·潮涡）**：圆形潮涡，粗螺旋 + 细回环 + 缺口小水滴，最适合放在方形头像/入口位；18px 会收成一个厚螺旋，细节会掉。
- **备选 C2（液态 R·浪腹）**：R 的识别度最高，16px 仍一眼是 R；但左竖笔底部是平切，且整体比 C4 静。
- **不建议**：B2（笔触飞白太多，16px 糊成灰团）、C3（水花装饰太碎，16px 成一团），这两张只适合做插画参考，不适合入口图标。

## 逐张笔记

### A · 卷浪梢

**A1 单峰回卷**
- 提示词要点：一笔从左下涌起，形成碎浪峰，在右上向内卷；负空间留在卷心；最多两颗小飞溅；无底座、无边框。
- 优点：动势最完整，长尾有“退潮拖拽”的感觉，卷心明确；缩小后剪影仍是浪。
- 缺点：笔刷飞白和细线太多，16px 会丢掉一部分纹理；左右跨度偏宽，方形图标里略占地方。
- 18px：仍读作卷浪，是 A 组里最稳的。

**A2 螺旋浪舌**
- 提示词要点：长斜尾 + 紧卷浪舌，整体斜向，卷心留大负空间，一条连续带。
- 优点：线条优雅，160px 很像一个“6”或浪的符号，方向感强。
- 缺点：只有“卷”没有“回潮”，潮汐的进退感弱于 A1/A3；16px 容易只剩一个钩形/音符。
- 18px：可读，但更像抽象符号，不像浪。

**A3 浪脊与回潮**
- 提示词要点：主浪脊从左向右翻卷，下方一条回潮线贴着浪基，两条线构成一次“进—退”。
- 优点：线条最干净，进退关系明确，最接近“线图标”的完成度；留白舒服。
- 缺点：16px 时两条线会挤在一起，卷心变小，容易读成“e/螺旋”；气势比 A1 弱。
- 18px：好看，但需要把回潮线和主脊再拉开 0.5–1px 才不糊。

**A4 潮涌剪影**
- 提示词要点：整块实心潮涌剪影，左侧隆起、右侧钩状回卷，尾端收细，钩内留一个小负空间。
- 优点：16px 轮廓最清楚，冲击力强，适合做“实心图标”方向。
- 缺点：太像“浪块/clip art”，回卷的连续动势弱；左侧底部有一条明显的平切边，像被裁过。
- 18px：能读成浪，但更像“海浪图标”而不是“潮汐”。

### B · 回旋环流

**B1 潮涡**
- 提示词要点：粗弧向内螺旋，叠一条细回环，留一个缺口，偏心“眼”，缺口处最多一颗小水滴。
- 优点：圆形构图完整，潮涡/潮池的循环感强；粗细节奏好，放在方形入口位很稳。
- 缺点：细节最多的一张，18px 会变成厚螺旋 + 一个点，细回环基本消失；容易联想到“加载/刷新”。
- 18px：仍读作漩涡，但需要减少一圈细线。

**B2 双潮追尾**
- 提示词要点：两条潮水互相追赶，一粗一细两个月牙交错，端部收尖，留缺口。
- 优点：160px 很有动感，飞白有水墨味。
- 缺点：笔触太碎，16px 直接糊成灰团；旋转方向也不够明确。
- 18px：不合格，不建议进入矢量。

**B3 咬尾潮环**
- 提示词要点：粗带绕环、尾端抬起成小浪头、头尾几乎相接，环不规则、中心留白。
- 优点：比 B1 简洁，旋转感和“咬尾回卷”都强，18px 仍是一个有力的环形。
- 缺点：容易读成“G/回收/循环”图标，潮汐的自然感不如 A 组；环心略空。
- 18px：可读，是 B 组最适合小尺寸的一张。

**B4 双螺旋潮**
- 提示词要点：两条逗号形潮水互相咬合，像水的阴阳鱼，一粗一细，各带小卷。
- 优点：形式完整、平衡，160px 很漂亮。
- 缺点：太像太极/阴阳符号，对称、符号感压过潮汐感；缩小后就是一枚“阴阳鱼”。
- 18px：识别成符号，不像 Ria 的水。

### C · 液态 R

**C1 潮汐一笔**
- 提示词要点：一笔连续液体带写出大写 R，竖笔像涨潮、腹部像卷浪、腿像退潮拖尾。
- 优点：书法感强，R 可读；腿的长甩很有“退潮”味道。
- 缺点：左竖笔偏细、整体偏软；16px 虽然能读成 R，但笔画对比不够稳。
- 18px：可读，适合做更优雅的字标方向。

**C2 浪腹**
- 提示词要点：液体 R，腹部是卷浪，腿是退潮，竖笔略倾，无衬线，一条粗带。
- 优点：R 的识别度最高，16px 仍一眼是 R；腹部的卷浪和腿的甩势衔接自然。
- 缺点：左竖笔底部是平切，像没写完；整体比 C4 静，潮汐感中等。
- 18px：最稳的 R，矢量阶段把竖笔底部收圆即可。

**C3 涌潮字母**
- 提示词要点：R 作为潮汐字形，左竖是涌起的水柱，腹部紧螺旋，腿是碎浪，实心 + 负空间。
- 优点：装饰性最强，160px 很有海报感。
- 缺点：水花、飞沫、卷浪太多，16px 直接成一团；不适合入口图标。
- 18px：不合格，只建议做插画/启动页参考。

**C4 倒影**
- 提示词要点：实心液体 R 剪影，腹部顶端带钩状浪冠，腿像退潮一样收细，竖笔是平滑的水柱。
- 优点：剪影最完整，18px 仍是一枚有分量的入口标；R + 浪冠的结合最自然。
- 缺点：极小尺寸下，顶部浪冠和 R 的腹部可能被读成 A/R 之间；整体偏静。
- 18px：最适合“入口图标”的一张，矢量阶段要把 R 的腿和腹部开口交代得更清楚。

## 小尺寸实测

把每张按 2× 设备像素渲染成 16/18/24px，再放大观察（临时图，未提交）：

- 16px 仍能读出主体：A1、A4、B1、B3、C1、C2、C4
- 16px 开始糊：A3（两条线并在一起）、C4（A/R 轻微歧义）
- 16px 不合格：B2（灰团）、C3（碎团）
- 18px 最稳：A1、C2、C4、B3

这也说明：位图阶段选的是“动势和剪影”，不是最终像素；真正做 24×24 矢量时，线条数量还要再减一轮。

## 推荐 3 张

1. **A1 · 单峰回卷** —— 最像“潮起潮落”的 Ria：有涌起、有翻卷、有拖尾。首选。
2. **C4 · 倒影** —— 最像一枚入口图标：实心、稳、R 与浪冠一体。若希望侧栏一眼看到“Ria 的 R”，选它。
3. **B1 · 潮涡** —— 最像“潮池/环流”：圆形构图，适合方形入口或头像位。若希望图标更安静、更几何，选它。

如果只想要“最清楚的 R”，用 **C2** 替代 C4；如果只想要“最干净的线图标”，用 **A3** 替代 B1。B2、C3 不建议继续。

## 下一步

- 等选定 1 张后，再按 24×24、`fill="none"`、`stroke="currentColor"`、round cap/join 重画矢量；位图只做参考，不直接描。
- 矢量阶段优先保留：A1 的长尾 + 卷心；C4 的 R 骨架 + 浪冠；B1 的粗螺旋 + 缺口。
- 不涉及原神官方水元素图形；这批是原创几何/笔势。

## 复现

```bash
export AIGC_APPID='<your-appid>'
python3 docs/icon-concepts/v3/.gen/generate.py --all --workers 3
```

脚本会读取 `.gen/prompts.json`，把结果写到 `raw/`；`contact.png` 由 `raw/` 重新排版生成。
