# Ria 水元素图标候选 v2

## 0. 一句话

这一轮把「水」做成有动势的一笔，而不是三条水平线：**首推 V1 卷浪梢**，18px 侧栏仍有清楚的卷浪轮廓；V2 回旋环流是更安静的备选，V5 液态 R 适合优先保留字母识别。

## 1. 目标与约束

- 载体：Ria 侧栏入口 / 欢迎卡片，16–24px 为主，最大 48px。
- 气质：灵动、非对称、有方向感；不是几何水平线，也不是原神水元素的描改。
- 技术：24×24 viewBox；根节点 `fill="none"`、`stroke="currentColor"`；圆头圆角；用分段 `stroke-width` 造粗细变化；无渐变、遮罩、filter。
- 判断标准：160px 看概念与动势，16px 看是否还像水，18px 看侧栏是否立得住。

### 关于实心水滴

根节点仍是 `fill="none"`。V3 的三滴水滴、V4 的主水滴与飞溅圆点使用 `fill="currentColor"`：水滴是实体，不是线框；若强行全描边，16px 会退化成空心冒号/小圆圈，直接失去「滴」的识别。这是本轮唯一偏离纯描边的地方，没有使用任何渐变、遮罩或滤镜。若必须全部描边，V3/V4 需要重新设计成更粗的闭合轮廓，16px 效果会明显变差。

## 2. 逐版说明

### V1 卷浪梢（推荐）

- 构成：一条从左下涌起、向右上卷回的开放曲线，线宽 2.3；卷心向内收，尾部留在左下；右上方两颗飞溅圆点（0.75 / 0.5）。
- 动势：不是对称波浪，而是「起—扬—卷—收」的一次呼吸；重量压在卷心，尾部轻，视线被带着向右上走。
- 160px：卷浪的厚度与内卷很清楚，两颗水珠把「浪梢」点活。
- 16px：仍能读出卷浪/水花，圆点在 16px 合成一个小亮点，不抢主体；这是五版里小尺寸最稳的一版。
- 18px 侧栏：轮廓完整、留白够，和文字并排不会糊成一团。
- 风险：极端小尺寸（≤14px）会偏像「6」或钩子；16px 及以上成立。
- 线宽取舍：试过把尾部压到 1.5、身体加到 2.4 的分段粗细，160px 接头处会出现明显台阶，像断笔；最后保留 2.3 的均匀线宽，动势交给曲线、重心和飞溅点。
- 结论：**首选**。它同时满足「一眼是水」「有动势」「缩小不散」。

### V2 回旋环流

- 构成：三段圆弧 2.6 → 1.8 → 1.2，围出一个有缺口的环；内圈一条 1.1 的回声弧；缺口下方一颗 0.85 的水滴。
- 动势：水绕着中心回流，缺口让环「漏」出去，避免成为封闭的几何圆。
- 160px：环流与内圈回声有层次，像漩涡/回旋镖。
- 16px：读作带缺口的环/旋涡；因为形态接近刷新/加载图标，单独看可能先想到「循环」而不是「水」。
- 18px 侧栏：安静、稳，适合不想太张扬的入口；但辨识度依赖缺口水滴。
- 风险：太像 loading/refresh 图标；水滴在 16px 只剩一个点。
- 结论：**第二选择**。想要更抽象、更平静的标记时选它。

### V3 三滴错落

- 构成：三颗实心水滴，沿左上→右下斜线错落；大滴 0.95（右下）、中滴 0.64、小滴 0.42；角度 18° / 4° / -16°，让三滴不同时指向同一方向。
- 动势：像一串正在坠落/溅起的水滴，重心压在右下大滴，左上小滴负责「远」和「轻」。
- 160px：三滴的大小节奏和非对称角度很好看，是五版里最「装饰」的一版。
- 16px：三滴会退化成三个实心点，失去水滴尖；能读出「三点水」的意象，但不如 V1/V2 明确。
- 18px 侧栏：大滴的尖开始出现，能看出是水滴；适合放在偏图形、弱文字的场景。
- 风险：16px 像标点/省略号；三滴的间距在 16px 容易粘成一条。
- 结论：**大尺寸/装饰优先**，不建议作为唯一 16px 入口。

### V4 水花迸溅

- 构成：一颗向左倾斜 12° 的主水滴（0.88），左下一条低弧 1.6，右上一条长弧 1.4 接一小段尾 1.0，另有两颗飞溅圆点（0.55 / 0.45）。
- 动势：水滴在掠过水面的一瞬间带起尾迹；左低右高，重心偏右下，尾迹向右上甩出。
- 160px：像一颗带溅射尾迹的水滴，动势最强，不是对称的「人」或「水母」。
- 16px：主水滴还在，但两条弧会并成一条斜线，可能先读成彗星/叶子/对勾；水的识别依赖主水滴。
- 18px 侧栏：比 V3 更有方向感，适合想要「快」和「轻」的入口。
- 风险：弧线与水滴的衔接在 16px 会变糊；右侧尾迹太细会消失。
- 结论：**动态备选**；如果侧栏背景复杂，优先 V1。

### V5 液态 R

- 构成：三笔 2.5 / 2.0 / 1.4 连成一个 R；竖笔略弯，腹部圆转，右腿向右下踢出。
- 动势：像一笔倒出来的水，在末端收成字母；不是几何 R。
- 160px：R 的识别最强，液态感来自粗细过渡和圆转。
- 16px：五版里最清楚的一版，任何尺寸都不会散；但它首先读作 R，不是水。
- 18px 侧栏：如果 Ria 的品牌核心是「R」，这是最稳的入口；如果核心是「水」，它不够。
- 风险：水的语义弱；更像字母标。
- 结论：**字母标优先时选它**；否则作为备选。

### V6 涌泉（本轮未交付）

按「底部短弧托起 + 向上渐细水柱」做了多轮：长底座 + 单柱在 160px 像锚，16px 更像字母 t；三叉柱像仙人掌/三叉戟；短底座弯柱像钩子/虫子；水滴 + 涟漪又像「碗上放蛋」或一张脸。**涌泉这个纵向结构在 16px 会稳定退化成锚/植物/字母 t，无法满足「16px 仍看出水」的硬约束**，所以本轮不交付 v6.svg，只交 5 版（在你给的 5–6 版范围内）。如果之后愿意把入口尺寸放到 20px+，可以再单独做一版涌泉，或把它做成更大的场景插画，而不是 24px 图标。

## 3. 对比与推荐

| 版本 | 概念 | 160px | 16px | 18px 侧栏 | 推荐度 |
| --- | --- | --- | --- | --- | --- |
| V1 | 卷浪梢 | 卷浪清楚，有水珠 | 仍像卷浪/水花 | 最稳，动势与留白平衡 | ★★★★★ |
| V2 | 回旋环流 | 环流有层次 | 像带缺口的环 | 安静，略像刷新图标 | ★★★★☆ |
| V3 | 三滴错落 | 三滴节奏好 | 退化成三个点 | 大滴可见，偏装饰 | ★★★☆☆ |
| V4 | 水花迸溅 | 尾迹动势强 | 水滴 + 一条斜线 | 有方向感，略像彗星 | ★★★★☆ |
| V5 | 液态 R | R 清楚，液态过渡 | 最清楚 | 字母标最稳，水感弱 | ★★★★☆（字母优先） |

**推荐顺序：V1 > V2 > V5 > V4 > V3。**

- 如果只能选一个放到 18px 侧栏：**V1**。
- 如果想要更抽象、更「静」的品牌感：**V2**。
- 如果 Ria 的识别首先靠字母 R：**V5**。

## 4. 复现

```bash
node docs/icon-concepts/v2/.build-preview.mjs

google-chrome --headless --no-sandbox --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --user-data-dir=$PWD/.chrome-v2 \
  --window-size=1120,1620 \
  --screenshot=docs/icon-concepts/v2/preview-large.png \
  file://$PWD/docs/icon-concepts/v2/preview.html

google-chrome --headless --no-sandbox --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --user-data-dir=$PWD/.chrome-v2 \
  --window-size=720,860 \
  --screenshot=docs/icon-concepts/v2/preview-small.png \
  file://$PWD/docs/icon-concepts/v2/preview-small.html

google-chrome --headless --no-sandbox --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --user-data-dir=$PWD/.chrome-v2 \
  --window-size=1092,292 \
  --screenshot=docs/icon-concepts/v2/wet-chat.png \
  file://$PWD/docs/icon-concepts/v2/wet-chat.html
```

Chrome 157 必须带 `--user-data-dir`，否则会报 `Failed to create a unique user data directory for headless`。截图是 2×，预览里的 16px 对应 32 设备像素，接近 Retina 侧栏的实际观感。
