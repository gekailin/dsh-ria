# README「经典用法」候选清单

> 用途：给 README 首屏挑示例。每条都是用户对阿汐说的原话，下一行是 README 里的浅色小字解释。
> 统一约定：worker 一律用「阿X」人名；第一条示范怎么建员工、怎么起名。

## 命名约定

阿X = worker 会话的名字（阿程=开发、阿测=测试、阿检=代码体检、阿文=文档、阿研=调研）：阿汐建员工时可以自己起名，之后你直接喊名字派活。

## 场景候选（12 条）

覆盖：建员工并派工、带参考图派活、纠正、配置运维（权限/模型/微信）、验收返工、调研探讨、追问进度、定规则、目标澄清、串行安排。标「主推」的共 7 条。

### 1. 建员工，派第一单 ｜ 主推

**「阿汐，建一个员工『阿检』，review 一下 dsh-ria 项目的代码。」**

<sub>阿检是给这个新 worker 起的名字；她建好会话、写明职责，再把 review 派过去，盯到报告出来。</sub>

来源：§4 A 派工（48 条，28.6%）；旧 README 的“全仓体检”场景；§5 祈使动词（开/建）。

### 2. 带参考图派活 ｜ 主推

**「阿汐，这张账单页设计稿发给阿程，让它照着改，交互别动。」**

<sub>她把图作为附件交给阿程，连同“只改视觉、不动交互”的边界一起写进验收。</sub>

来源：§4 H 贴图（32 条，19%）；L6742 的 E2 图 +「用 e2s-1.jpg，重命名并更新文档头图」是同一类“以图代描述”。

### 3. 派错了，先停下 ｜ 主推

**「阿汐，你派错了，先停下——这个活是阿研的，不是阿程。」**

<sub>她先停掉阿程，再把任务和上下文转给阿研，并告诉你重派结果。</sub>

来源：§4 C 纠正（26 条）；§2 P1-1（T20 L1549「我停掉worker是因为你发错了，不要再发了」）。

### 4. 开权限 ｜ 备选

**「阿汐，给阿文开一下这个仓库的写权限，只开 docs/。」**

<sub>她按最小范围调整阿文的权限，改完把生效范围和回滚方式一起告诉你。</sub>

来源：§4 E 配置运维（17 条，10.1%）；旧 README 的临时权限场景。

### 5. 换模型 ｜ 备选

**「阿汐，把阿程换成 deepseek-v4，再让它接着跑登录页那个活。」**

<sub>她换好模型后把中断的上下文接上，仍按原来的验收标准收尾。</sub>

来源：§4 E 配置运维；现有换模型能力。

### 6. 连接微信 ｜ 备选

**「阿汐，把微信连上，之后任务收尾的消息发到文件传输助手。」**

<sub>她引导你扫码，连好后把收尾汇报同步到微信；连接状态在侧栏「连接」里。</sub>

来源：§4 E 配置运维；T55/T174 的通道反馈；docs/wechat.md。

### 7. 验收返工 ｜ 主推

**「阿汐，搜索结果页的筛选条件没带上，让阿程返工一版；验收标准是筛选条件必须带上、空结果要有提示。」**

<sub>她把问题写成可验收的标准，退回阿程，改完按同一标准复核。</sub>

来源：§4 D 验收（14 条，8.3%）+ C 纠正（26 条）；§2 P1-2 报障要先要现象。

### 8. 调研探讨 ｜ 主推

**「阿汐，我们聊聊账单页要不要拆成两个 tab，先别动代码。」**

<sub>她先和你把取舍、边界和风险过一遍，等你说“就按这个来”，再落成能派的活。</sub>

来源：§4 F 调研提问（12 条，7.1%）；§5 提问式需求（23 条）。

### 9. 追问进度 ｜ 主推

**「阿汐，阿程那个登录页的活到哪了？卡住就告诉我卡在哪。」**

<sub>她查一下阿程的当前进度，遇到卡点带着原因来问你，而不是等到最后才说“做不完”。</sub>

来源：§4 B 进度追问（10 条，6.0%）；§5「看看/查查」句式。

### 10. 定规则 ｜ 备选

**「阿汐，记一下：以后我说“盯一下阿程”，就是让你每完成一单都回我一句，不用等我问。」**

<sub>她把这条规则记进长期记忆，之后按这个方式汇报。</sub>

来源：§4 I 规则/记忆（6 条，3.6%）；L7955 的同类原话。

### 11. 目标不清楚，先问一句 ｜ 主推

**「阿汐，让阿研把新图融入跑一下。」**

<sub>她会先问一句：你说的是阿研这个员工，还是它最近那个“新图融入”的任务？确认后再派。</sub>

来源：§2 P2-5（T10 L796/L907）；§5 实体消歧：先问一句，别先全库检索。

### 12. 串行安排 ｜ 备选

**「阿汐，等支付回调联调完，再让阿程接后台导出。」**

<sub>她记住先后顺序，前一件没收尾就不催后一件；轮到阿程时把上下文一并交过去。</sub>

来源：§5 触发词「先…再」（18 条，11%）；旧 README 的“先做 A 再做 B”。
