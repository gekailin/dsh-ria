# Ria 入口图标候选 v1–v6

本目录只放**候选**：6 个独立 SVG + 一张对比预览 + 本说明。`lib/client.js` 的 `RiaIcon` 未改动，选定版本后再替换。

> 另见「海浪 / 海螺」方向的 6 个候选：`wave-conch/`（v1 双浪、v2 卷浪、v3 浪环、v4 螺旋海螺、v5 海螺归潮、v6 鹦鹉螺）。
> 另见「R 形浪」：`v3/` 是 A1/A3 的位图源，`v4/` 是把 A3 推向 R 的 6 个变体与矢量探路（A1 留作备用）。
> 另见「R 形浪 v5」：`v5/` 是在 A3 上做 6 个最小编辑、并把 A3e-4 做成 24×24 填充矢量的实验（`trace-fill.svg`，带填充，与上面的 stroke 规格不同）。

## 共同规格

- 24×24 viewBox，`fill="none"`，纯 stroke 描边，无渐变、无阴影、无底色；
- `stroke="currentColor"`，`stroke-linecap/linejoin="round"`，线宽 1.7（v6 为 1.8）；
- 主体控制在 24 网格中央约 16px 的光学框内，48px 下目视检查重心居中；
- 侧边栏以 18px 显示，折叠态也只有图标，因此优先保证 16–18px 的轮廓清晰。

## 逐版说明

### v1 涟漪 · 信号（抽象）
- 意图：左侧信标圆点 + 两道向右扩散的弧，呼应「潮汐 / 回声」，也暗示「消息发出去会被接住」。
- 适用：最不指代具体物件，和 DSH 侧边栏现有细线图标并排时区分度最高；适合弱化「管家」直白感、强调「回应」的品牌方向。
- 16px 可读性：点 + 第一道弧清楚，第二道弧退化成一条短线，整体近似「音量 / 信号」图标；可读但可能被误读为通知音量。

### v2 交叠 · 协作（抽象 / 几何）
- 意图：两个等半径圆相交，表示「我 + worker」的交接面，交叠区即协作本身。
- 适用：语义最贴「协调者」，且完全用几何语言表达，不借用铃铛/钥匙这类既有物件。
- 16px 可读性：两圆在 16px 下交叠成「眼镜」或「链环」，仍可辨认；与「链接」类图标同列时可能混淆。

### v3 标签页 · 会话管理（语义）
- 意图：前后两张圆角「标签页」，对应「多个会话被收拢、归档、追踪」。
- 适用：和 Ria 的「会话管家」职责一一对应，是六版里语义最具体的一版。
- 16px 可读性：后面那张「页」只剩一个 L 形拐角，16px 时容易被看成「复制」；24px 以上最清楚。

### v4 服务铃 · 管家（语义）
- 意图：前台服务铃（钟形主体 + 底边 + 铃舌），「按铃即到」的管家意象。
- 适用：轮廓闭合、重心稳，48px 下最像成品图标；适合希望入口一眼被认成「服务 / 助理」的场景。
- 16px 可读性：铃身与底边之间只有约 1px 空隙，16px 下可能连成「Ω」；铃舌缩到 16px 只剩一个小点，仍可接受。

### v5 钥匙 · 授权（语义）
- 意图：横向钥匙（环 + 杆 + 两齿），代表「把任务授权 / 转交给对的 worker」。
- 适用：强调 delegate 与权限语义；横向构图在竖排列表里比斜置钥匙更稳。
- 16px 可读性：两齿与杆间距很小，16px 下齿部容易糊成一块；若要选它，建议 16px 场景只保留一齿。

### v6 R 字母标（字标）
- 意图：几何单线 R，直接绑定「Ria」这个名字，不再承载物件隐喻。
- 适用：需要长期品牌识别、且不希望入口图标被读成某个具体功能时。
- 16px 可读性：碗部与斜腿笔画偏细，16px 下斜腿起笔处可能显得断开；若选它建议加大碗部开口或把线宽提到 1.9。

## 取舍建议

- 想要「一眼看懂是助理 / 管家」：v4 铃铛最稳，v3 次之。
- 想要「品牌感 + 与现有侧栏图标同风格」：v1 涟漪最协调，v6 最像字标。
- 想要「协调者」而非「服务者」：v2 交叠最准确。

六版都通过同一套约束（24 网格、1.6–1.8 描边、currentColor、round cap/join），替换时只需改 `RiaIcon` 的 `d`/`circle` 子元素，样式与尺寸接口不变。
