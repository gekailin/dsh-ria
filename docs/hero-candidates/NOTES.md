# Hero 候选 A / B / C / D

A/B/C 三版和 D 组三版都是 1376×768，左文右图，浅青主调；人物延续现有 `docs/hero.jpg`：青绿长发、贝壳发饰、珍珠耳饰、深蓝马甲、白衬衫、青绿领结、浅蓝百褶裙、黄铜提灯。

A/B 保留原字标「阿汐 · Ria」；**C 已选定**，并把 R 换成 v7 浪形 icon，`ia` 默认用当前 Noto Sans Black。A/B/C 共用同一套面板、文字颜色和版式，只有画面气质、细节密度和 C 的 R 处理不同；D 组以 C-model-ia.jpg 为基准，只重做左侧面板与接缝。

## 共同做法

- 底图：`gemini-3-pro-image`，2K（2752×1536，16:9），图生图。参考图由 `docs/hero.jpg` 清理掉旧文字后得到，保留人物、姿势和构图。
- 排版：2× 渲染后用 Lanczos 缩到 1376×768。左侧是磨砂浅青面板：底图高斯模糊后与 `#E8F9F9` 混合，再向右羽化，给文字让出干净区域；右侧保留人物和场景。
- 文字：全部用 PIL 叠加，不让生成模型写中文或英文，避免错字和字形漂移。
- 字号/颜色（最终像素）：
  - `DEEPSEEK HARNESS` — Noto Sans CJK SC Medium 22px，字距 8px，`#2D707A`
  - A/B 标题 `阿汐 · Ria` — Noto Sans CJK SC Black 94px，字距 2px，`#0F3540`
  - C 标题 `阿汐 · [icon]ia` — 中文和间隔点同上；icon 高 74px，与标题同色；`ia` 为 Noto Sans CJK SC Black 94px，字距 2px
  - `潮来汐去，万事有绪` — Noto Serif CJK SC SemiBold 43px，字距 3px，`#174B56`
  - `Tide may roam — every wave comes home` — Noto Sans CJK SC Light 21px，字距 1.5px，`#34636C`
  - 分隔线 `#4C9AA3`；文字位置：kicker (104,132)，标题基线 y=280，分隔线 (104,310)，中文 (104,342)，英文 (104,430)。

## A · 细节丰富版

- seed 20261112
- 提示词要点：更密的发丝高光、衣褶和裙摆层次；结构完整的黄铜灯笼（玻璃、提梁、暖光、流萤）；潮汐粒子、漂浮票据和玻璃中庭的纵深。
- 观感：人物、灯笼和场景层次最完整，右侧信息量最大，最接近“阿汐在潮汐中派发任务”的叙事。
- 适合：想要更多细节、更强叙事感的首图。

## B · 清透留白版

- seed 20261113
- 提示词要点：high-key、细线、水彩式淡彩、更少的漂浮卡片和背景细节、更大的负空间。
- 观感：最轻、最干净，人物和灯笼都退到更柔的对比里；左文右图的呼吸感最好。
- 适合：浅色文档站、需要安静阅读氛围的页面。

## C · 光影氛围版（已选）

- seed 20261114
- 提示词要点：午后青金色调、灯笼暖光、体积光、深青阴影、反光地面和更丰富的空气感。
- 观感：对比最强，灯笼是视觉中心，人物从暗部里被暖光照亮；左侧面板与右侧暗部的反差也最大。
- 适合：深色主题、入口页、需要戏剧性的场景。

### C 的 R 替换

- icon 来源：`docs/icon-concepts/v7/wave-faithful.svg`（侧栏同一个 v7 faithful 浪形）。4× 渲染，按 alpha 通道重新着色为 `#0F3540`，高度 74px（略高于 R 的 70px cap height），底边对齐标题基线；相对原 R 位置左移 6px，与 `ia` 间距 5px。
- `C.jpg`：`ia` 用当前 Noto Sans CJK SC Black 94px，字距 2px；标题总宽约 525px，结束于 x≈629。与中文同族，最稳。
- `C-icon-serif-italic.jpg`：`ia` 用 Noto Serif CJK SC Black 94px，再向右斜切 10%；衬线的粗细对比和斜势更接近浪形 icon，更像一个独立 mark。
- 两版并排：`C-icon-options.png`。`C.jpg` 保留当前字体版；如果要换，另存新文件，不覆盖现有 `A.jpg` / `C.jpg`。

## 取舍

C 已选定：光影和灯笼最突出，R 换成 icon 后左文右图的品牌感也最强。A/B 保留作对照；如果最后改用 A/B，需要同样做一次 R 替换。三版都没有覆盖 `docs/hero.jpg`，确定最终版本后再单独替换。

> 说明：漂浮票据里只有抽象线条，没有可读文字；三版生成时都要求 no text / no letters，排版文字和 C 的 icon 都是后期叠加的。

## C 的 ia 改为模型绘制（新增，保留 C.jpg）

- 按用户要求，`ia` 也交给图像模型绘制，不使用现成字体；`A.jpg`、`C.jpg` 和现有候选都不覆盖。
- 新文件 `C-model-ia.jpg`（推荐）：`gemini-3-pro-image`，1:1 2K，seed 20261124；提示词要求 high-contrast serif、短促上挑的浪尾、纯白底、画面只有 `i` 和 `a`。提取 alpha 后重着色 `#0F3540`，按 x-height 对齐，基线仍是 y=280，标题结束 x≈631。
- 备选 `C-model-ia-classic.jpg`（seed 20261121，经典衬线）、`C-model-ia-wave.jpg`（seed 20261122，长浪尾）；`C-model-ia-options.png` 是 2× 标题对照（包含当前 C.jpg 的字体版）。
- 模型只画 `ia`；中文「阿汐 · 」和 icon 仍是后期合成。`C.jpg` 保持原样。

## D 组 · 降低左侧与右侧的反差（新增，不覆盖 A/B/C）

- 基准是 C-model-ia.jpg；A/B/C 和 docs/hero.jpg 都没有改动。D 组仍是 1376×768，人物、标题、字号、位置和模型绘制的 ia 与 C-model-ia 完全一致，只重做左侧底色、纹理和接缝。
- 左面板不再是平涂：左上保留暖青白，向右逐步过渡到青灰绿，接缝附近接近右侧场景的中间调；文字仍压在较亮的一侧，不靠降低字号或改字色来换可读性。
- 文字层从 C-model-ia.jpg 提取 alpha，再按原色重着色：kicker #2D707A、标题/icon #0F3540、中文 #174B56、英文 #34636C、分隔线 #4C9AA3；位置仍是 kicker (104,132)、标题基线 280、分隔线 (104,310)、中文 (104,342)、英文 (104,430)。文字下加 9px 白色柔光（alpha 0.42）；D3 另外加 15% 的柔光文字底。

### 接缝做法

- 左侧替换遮罩从 x=730 保持 1，到 x=802 归零；只在原图较亮的位置替换，人物头发和暗部用亮度 guard 保留，避免把人物边缘一起刷掉。
- 遮罩之上再叠 9px 高斯模糊桥接（中心 x≈752）和 11–13% 的青雾（中心 x≈758），把“面板边缘”摊成一条渐隐带，而不是一条硬边。
- 左侧底纹来自右侧场景：裁 x=760–1376，水平翻转，72px 高斯模糊，再向浅色抬亮；D1/D2/D3 分别以 12%/23%/30% 混入。越靠接缝混入越多，文字区最少。

### D1 · 暖调渐变（最克制）

- 色标：#F7FBF5 → #F1F9F2 → #E1F4EC → #CFEBE3 → #BEE0D9 → #A9D1CA → #94BEB8（0–0.64W）。
- 左上叠 #F4E2C5 12% 暖光；12% 右侧底纹；无手绘线、无票据。接缝最干净，适合不想让左侧出现具体物件的情况。
- 文字对比度（按文字框邻域背景估计）：标题约 11.4:1，中文约 8.4:1，英文约 5.8:1，kicker 约 5.1:1；最差局部约 4.9:1。

### D2 · 同源底纹（玻璃结构 + 票据）

- 渐变比 D1 略冷：#F5FAF5 → #ECF7F0 → #D9F0E9 → #C6E7DF → #B3D9D2 → #9DC7C1 → #86B2AC（0–0.64W）；#F5E4C7 暖光 12%。
- 23% 右侧底纹；玻璃竖梃在 x=540–684，分两段（y=60–190、470–740）避开文字，另有 y=88/178/488/720 的横档；三张漂浮票据剪影放在 (472,512)、(568,584)、(382,640)。
- 观感：左侧开始有“中庭玻璃”的结构线，但仍以渐变为主；票据只提供尺度，不抢文字。
- 对比度：标题约 11.0:1，中文约 8.2:1，英文约 5.6:1，kicker 约 4.9:1；最差局部约 4.7:1。

### D3 · 手绘潮汐（纹理最多，推荐）

- 渐变带暖金：#FAF8EE → #F6F8EE → #E3F5EB → #CBEBE1 → #B8DED6 → #9EC9C2 → #84B2AB（0–0.64W）；左上 #F6E2C0 暖光 16%，底部再叠 7% 青绿水色。
- 30% 右侧底纹；下半部 6 条潮汐线（y≈520–690）、28 个气泡、3 张票据、46 个金色微粒；文字区加 15% 柔光底，保证压住纹理。
- 观感：左侧第一次像“画出来的潮汐”，和右侧裙摆、地面的水纹接上；上半部仍留白给标题，下半部才有细节。D3 的纹理最多，但文字仍是全组最清楚的之一。
- 对比度：标题约 11.1:1，中文约 8.2:1，英文约 5.6:1，kicker 约 4.9:1；最差局部约 4.8:1（kicker 22px，仍高于 4.5:1 的 AA 阈值；文字柔光还会再抬一点局部反差）。

### 推荐

- **首选 D3**：它同时解决了“左侧太白”和“左侧没有内容”两个问题，潮汐线/气泡/票据与右侧同一套意象；文字对比度仍达标。
- **D1 作为稳妥回退**：最干净，适合不希望左侧出现任何具体物件的版式；如果只想要“换色 + 宽羽化”，选 D1。
- **D2 是中间态**：玻璃结构比 D1 多一层空间感，但纹理比 D3 克制；适合担心潮汐线太抢眼时使用。
